Fine tuning of models is becoming increasingly popular with current improvements in LLM's potentially attributed to distllment training methods from a stronger in class model. Specifically, OPUS 5 --> 5.5 token efficiency dramatically improved as did performance, even over the "all poweful" Fable flagship. It is posited that this improvement over such a fast period of time doesn't come from better data or smarter training from humans but rather a model distilled from a more powerful that Antrhopic has access to. This has a few driving reasons but the main one is the token efficiency aspect, it is very intuitive that a distilled model (something similiar to taking last layer of outputs and fine tuning from there) can reduce the cost of a model's use rather by cutting down layers from a better model rather than one that requires all the layers at once.

Given this I propose a test of LLM's trading financial assets in a simulated environment. I propose getting a small local LLM and give it some data with strict guidelines - i.e. no ML algo's allowed (defeats purpose), no updating weights etc. - versus one that is essentially fine-tuning itself to the data it is given and seeing how they perform. A few issues here are likely to do with how to run a "small" (still 30B params likely, if using expert model i.e. already fine tuned QWEN 30B for coding that activates about 3B) this will still be difficult to run locally. I intend to see price of renting GPU instance for this and future a better test may be NN, LSTM and transformer performance on the OOS trading (simple trading rules) with a train/val set as well as truly unseen blind set (val used for early stopping) and then seeing how the performance here (measure via accuracy, sharpe, and performance under trading rules) on the blind set varies to one where we take the final weights and fine-tune from there into a smaller model.

Challenges will be sourcing data + simulation as financial data is noisy so a large portion of this would be dedicated to feature engineering etc.
